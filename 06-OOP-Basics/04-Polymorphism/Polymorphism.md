# Polymorphism (تعدد الأشكال)

This module focuses on **Polymorphism** in Python, demonstrating how different classes can implement identical method signatures to produce dynamic, class-specific behaviors.

---

## Topics & Files Included

| File Name | Description | Key Concepts |
| :--- | :--- | :--- |
| `01_polymorphism_basics.py` | Introduction to Polymorphism using uniform interface calls. | Shared Function Names across unrelated classes (Salary & Payments). |
| `02_polymorphism_challenges.py` | Practical tasks on parameter-based interfaces. | Uniform Interfaces, Flexible Method Execution (Ride Fares & Utility Bills). |

---

## Key Takeaways for Students

1. **Uniform Interface**: Calling the same method name on different object instances without needing conditional statements (if/else).
2. **Dynamic Behavior**: Each class provides its own tailored implementation for the action.
3. **Clean Code**: Reduces code complexity and makes systems easily extendable with new types.

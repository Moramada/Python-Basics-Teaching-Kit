## Instructor Notes & Common Edge Cases

When teaching these topics to beginners, special focus is placed on common failure points:

### 1. Data Type Casting
_ Common Issue: input() always returns a string. Performing arithmetic operations directly on input() leads to string concatenation instead of addition.
_ Resolution: Explicitly converting inputs to int() or float() before processing arithmetic operations.

### 2. Division by Zero
_ Common Issue: Students often build simple calculators without handling num2 = 0 in division.
_ Resolution: Implementing conditional checks (if num2 != 0) to prevent runtime ZeroDivisionError.

### 3. Syntax & Indentation
_ Common Issue: IndentationError caused by inconsistent spacing in if-elif-else blocks.
_ Resolution: Enforcing 4-space indentation standard and explaining code blocks visually.

# Inheritance & Method Overriding (الوراثة وإعادة كتابة الدوال)

This module demonstrates how to implement **Inheritance** in Python to establish parent-child class hierarchies, promote code reusability, and override default behaviors using `super()`.

## Key Takeaways for Students

1. **Reusability**: Subclasses automatically inherit all attributes and methods from their Parent class.
2. **`super()` Function**: Used inside the child class constructor to call and initialize the parent class attributes properly.
3. **Method Overriding**: Allows a child class to replace the implementation of a method inherited from its parent with a custom implementation.
